# اپ اندروید نصاب مارسیتو

اپ نیتیو اندروید (Kotlin) برای اپ نصاب. خود اپ همان سایت **https://marsiro.ir/n** را داخل یک WebView باز می‌کند.
در نتیجه هر تغییری که روی سرور دیپلوی شود، بدون APK جدید به گوشی‌ها می‌رسد و **سرور هیچ تغییری لازم ندارد**.

## بخش‌های نیتیو
- **دوربین:** دکمه‌های عکس (`<input capture>`) مستقیم دوربین گوشی را باز می‌کنند.
- **موقعیت:** برای «حرکت کردم»، «رسیدم» و ثبت نصب، اجازهٔ موقعیت از خود اندروید گرفته می‌شود. اگر نصاب اجازه ندهد، زمان ثبت می‌شود ولی مکان نه.
- **لینک‌ها:** شمارهٔ مشتری با برنامهٔ تلفن و مسیریابی با نشان یا مرورگر باز می‌شود. هر آدرسی بیرون از `/n` (مثلاً اپ انبار) بیرون از اپ باز می‌شود.
- **ورود:** کوکی ورود ذخیره می‌شود و با بستن اپ از بین نمی‌رود.
- **دکمهٔ برگشت گوشی:** به صفحهٔ قبلی برمی‌گردد.
- **بدون اینترنت:** صفحهٔ «اتصال برقرار نشد» با دکمهٔ «تلاش دوباره» نشان داده می‌شود.
- **ظاهر:** آیکن و رنگ‌ها همان PWA است. اپ از اندروید ۷ (API 24) به بالا نصب می‌شود.

## گرفتن APK
هر پوش روی این پوشه، APK را در GitHub Actions می‌سازد (workflow «Nasab Android APK»):
1. Actions را باز کنید، آخرین اجرای سبز را انتخاب کنید و از بخش Artifacts فایل `marsito-nasab-apk` را دانلود کنید.
2. فایل zip را باز کنید و `marsito-nasab-N.apk` را روی گوشی نصب کنید. باید نصب از منبع ناشناس را اجازه دهید.

## امضای APK
- **بدون تنظیم:** APK با کلید `app/debug.keystore` امضا می‌شود. این کلید داخل مخزن است، پس همهٔ نسخه‌ها امضای یکسان دارند و روی هم نصب می‌شوند. برای پایلوت کافی است.
- **قبل از پخش گسترده:** یک کلید واقعی بسازید و در Settings → Secrets → Actions این چهار secret را بگذارید:
  - `NASAB_KEYSTORE_B64`: محتوای فایل `.jks` با base64
  - `NASAB_KEYSTORE_PASSWORD`
  - `NASAB_KEY_ALIAS`
  - `NASAB_KEY_PASSWORD`

  ```bash
  keytool -genkeypair -keystore nasab-release.jks -alias nasab -keyalg RSA -keysize 2048 -validity 10000
  base64 -w0 nasab-release.jks   # خروجی را در NASAB_KEYSTORE_B64 بگذارید
  ```
  توجه: نسخه‌ای که با کلید تازه امضا شود روی نسخهٔ قبلی نصب نمی‌شود. نصاب‌ها یک‌بار باید اپ قبلی را پاک کنند.

## ساخت روی کامپیوتر
اندروید استودیو را باز کنید و پوشهٔ `nasab-android` را باز کنید، یا:
```bash
cd nasab-android
./gradlew assembleRelease    # خروجی: app/build/outputs/apk/release/app-release.apk
```
